# 研究流程与完成标准

## 范围与证据

先确定研究问题、候选集合、目标物种和阶段、参照及其研究条件、拟比较终点、通路范围、名额及已有实验安排。未确定的参数单列，使用明确情景进行条件预测。每轮只推进约定研究范围；新增证据可能纠正结论，但不能借此无限扩建平台或追加研究问题。

保存实际读取的来源、摘录位置、访问层级、检索结果和计算输入输出。来源无法获取时保留实际尝试，允许用作者摘要作有限判断，不能称为全文核对。没有取得某结果不等于实验阴性；没有统计显著性也不等于功能等效。

观察粒度是“原研究—实际分子/制剂—实验对象—条件—终点”。来源别名合并到原研究；同研究不同剂量、时长、物种和终点保留独立记录。多物质论文须分别确定每个物质的贡献。前药、活性体、偶联物、盐型和代谢关系独立记录。

候选、目标物种蛋白及参考蛋白均按约定范围逐项处理。身份、序列实际使用、功能注释、对应关系和研究用途分别审核。缺少FUNCTION或可靠结构时，可用有证据的家族背景和机制推导；不能把背景写成该物质对该蛋白的实测作用。

## 方法与推导

每项适用方法实际执行后保存输入、参数和结果；不适用写具体理由。计算失败记录故障和已尝试的替代办法，只影响相关判断。不能因某节点难以对接便停止通路其余节点，也不能为凑齐表格进行没有解释意义的计算。

同靶点、可比协议内进行计算比较。原始跨蛋白得分不直接相加形成总毒性分数。结构/对接接近只支持结构或计算关系，不直接等于表型接近。状态范围不是生物重复误差或95%置信区间；单状态不证明稳定。计算方向、功能方向和最终毒性分别判断。

每个候选以完整句子回答：预计发生什么，相对参照怎样，最重要依据是什么，依赖哪些前提，有什么相反证据，什么结果会改变哪项判断。要区分：推翻预测、类推前提不成立、补证后更新原先并列的判断。

允许有条件的部分顺序和并列。不得为了“保守”一律撤销所有预测，也不得为了画图强行排满名次。置信程度依据直接性、条件可比性、冲突和迁移距离说明；不把资料数或主观评分换成概率。

选择代表物依据验证价值，与风险高低分开。每个名额须有明确问题、替代候选比较，以及支持/反对结果的更新范围。应说明未覆盖成员和机制；六种等少量代表的结果不能自动确证整个家族排序。

## 集中复核

保留首次分析、审核问题、源头整改及重新执行结果。先确认错误来自数据归属、科学判断还是导出，再修对应源头。扩查所有受同类逻辑影响的记录；只重做实际受影响计算和判断。反复发生的同类错误触发模块简化或替换，不叠加物质名称补丁。

科学复核从原材料和执行记录出发，逐候选检查；影响排序和选物的关键原文重点复读一次。最终审核须贯通原材料、正式分析和实际交付的全部工作表及网页，不留下字段语义、最终阅读效果的责任空档。复核者身份、访问范围与限制如实记录。

## 实验筹备并行

科研分析完成与实验开始实施是不同状态。

分析达到实验筹备条件：全范围已处理，条件预测/并列可解释，名单及替代方案清楚，每个实验有判别问题和更新规则，重大未解事项及影响已说明。它不要求全部机制先被实验确证。

实施前还需按本实验室实际情况确定：候选身份和材料、暴露浓度与阶段、给药/换水、对照、可用检测、重复与样本设计等。没有已确认值就保留待确认，不能从文献示例自动搬成实验安排。本技能不替代实验室操作规程。

可并行完成的筹备包括：核对库存及化合物身份清单、按已知信息准备试剂/样本记录、整理检测平台条件、列出待确认参数、把代表物的支持/反对结果做成判读表。公开资料和能完成的准备由AI主动完成；仅对现有材料无法确定且影响判断的条件集中询问。未经授权不下单、不联络第三方、不启动实际暴露。

工具迁移、追加图形、插件封装和新课题测试不得成为NOR实验准备的前置依赖。若用户后续只要求实验筹备，直接沿用当前分析，不要求重跑已完成研究。

## 可以结束本轮的条件

| 对象 | 必须取得的结果 | 不能替代它的过程产物 |
|---|---|---|
| 范围 | 全候选和约定通路记录完成适用分析，障碍有尝试/替代/影响 | 名录、映射、方法计划 |
| 判断 | 逐候选预测、依据、条件、反证、置信和更新规则 | 文献数量、单一对接榜单 |
| 决策 | 实际风险顺序/分组与独立的代表物建议 | 只说“需进一步研究” |
| 审核 | 原材料到实际交付的内容审核与阻断错误清零 | 哈希相同、字段齐全、数量一致 |
| 交付 | 同源三种成果、阅读/显示/筛选/导出检查，内部记录另存 | 只有脚本、工具安装或进度说明 |

有实质障碍且替代分析已尽到时，可以交付明确条件和边界的结论；不得把未尝试的工作列为客观限制。全部必需事项通过后停止，后续新问题另记，不继续无目的地优化。
