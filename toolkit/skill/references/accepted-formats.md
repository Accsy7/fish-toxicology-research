# 交付格式

默认沿用用户认可的00—07工作簿、四入口网页及科研图版。从[通用渲染入口](render-input.md)生成，数据与图形配置分开。资源：[工作簿规格](../assets/workbook-layout.json)、[空白模板](../assets/workbook-template.xlsx)、[网页CSS](../assets/web/report.css)。新课题替换内容、专业名称和数据行；用户提出其他展示需求时，按本次要求调整。

## 工作簿

| 表 | 内容职责 |
|---|---|
| 00研究范围 | 研究问题、参照、条件、实际范围、版本和目录 |
| 01代表物建议 | 检验问题、选择理由、替代物、结果如何更新判断 |
| 02全范围预测 | 各物质预测、风险比较、主要理由和疑点 |
| 03逐物质分析 | 完整推导、条件、相反结果、置信程度与检验问题 |
| 04实验资料 | 研究对象、实验条件、终点、实际结果、解释和来源 |
| 05计算核查 | 方法、适用范围、单位、结果、稳定性及必要的敏感性分析 |
| 06目标鱼蛋白范围 | 身份、序列版本、实际使用、功能、来源与状态 |
| 07参考成员与来源 | 参考蛋白身份、物种、功能、对应关系及原始来源 |

保留认可的列宽、字体层级、冻结位置、链接及基本行块。03使用逐物质的纵向分析块，06、07各自承担上述职责。字段含义或结构需要改变时先列新旧映射。行数随数据增减，长文本调整行高，展示全部范围并清除旧筛选和隐藏状态。

## 网页与图版

四个入口为全家族比较、机制与逐物质推导、结构/计算/实验、代表物与验证。沿用分组筛选、物质详情、关系详情、复制和下载功能；面板按本题适用的数据组织。正文可选择，表格使用HTML表格，保留富文本复制到Word。

机制图呈现具体蛋白与作用关系，区分激活、抑制、结合和间接联系。物种、测量层级、线型及颜色含义随图例说明。结构和接触面板使用实际结构、姿势和计算记录；按数据选择适用面板。

图版保持等比例缩放，默认180 mm宽、白底、统一字体与面板编号，输出SVG、PDF、PNG及对应数据。图内放短标签、数值和单位，完整图注与出处放图外。筛选后的画面、数据表和下载内容使用相同记录。检查正常宽度、窄屏及实际导出文件。

## 生成与修订

各成果读取同一正式分析，科学内容修订后重新导出。登记分析版本、展示映射和渲染版本，内部记录单独存放。已有成果另存版本；默认交付包含图版、XLSX和网页，独立DOCX按用户需求生成。
