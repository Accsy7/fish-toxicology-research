# 已认可的科研交付格式

采用已认可的科研交付格式。样式见[网页CSS](../assets/web/report.css)、[工作簿规格](../assets/workbook-layout.json)及[空白工作簿格式](../assets/workbook-template.xlsx)。空白格式保留列宽、字体与行块，不含示例科学数据。格式认可不等于科学预测已经实验确证。

## XLSX

保持00—07顺序和基本布局。新课题可替换课题名称和确有必要的专业字段；业务字段增删、含义变化先列对照，不随意重组最后两表。示例的70/196/603及物种名称不是新课题常量。

| 表 | 内容职责 | 写入边界 |
|---|---|---|
| 00研究范围 | 问题、参照、比较条件、实际范围、各分支贡献、版本及目录 | 不放软件操作手册、哈希、内部修改过程 |
| 01代表物建议 | 名额问题、理由、替代、结果如何更新判断及未测成员 | 名单与风险榜单分开，条件与敏感性可见 |
| 02全候选预测 | 预测、关键依据、疑点 | 不复写03全部推导 |
| 03逐物质依据 | 完整推导、条件、反证、置信、可推翻与更新规则 | 审定正文，不引用聊天、旧版和内部裁决指令 |
| 04实验依据 | 研究对象、实验条件、测量终点、实际结果、必要解释、来源 | 终点不能代填对象；观察不自动复制成解释 |
| 05计算核查 | 方法、适用范围、单位、中位值/状态范围/状态数、稳定性、必要敏感性 | 计算比较不能冒充毒性排序 |
| 06目标鱼蛋白范围 | 身份、蛋白版本/实际使用信息、作用与用途、来源、状态 | 显示全部范围，清除旧筛选与隐藏；完整SHA另存 |
| 07参考成员与来源 | 参考身份、物种、功能证据、对应及原注释来源 | 有效/待定/否决、实际用/可用/历史用分别表述 |

不恢复“06应用配置”；不添加空白专家意见。保留原列宽、字体层级、冻结位置、基本行块结构及链接。长文本按内容适应行高，不能缩小字号掩盖溢出。表行数随本次数据改变。

## 网页

保持四个入口：全家族比较；机制与逐物质推导；结构、计算与实验；代表物与验证。概览给决定判断的关系和数值，点击展开具体物质、条件、反证与原始出处。

正文是可选择的普通富文本；表格使用真正的`table/thead/tbody/tr/th/td`及`text/html`复制，不用CSS网格或截图冒充可编辑表格。保持原有复制到Word功能。图注、来源和方法条件放在对应图或记录旁的按需详情，不另列绘图参考介绍或工程检查栏目。

数据、详情、筛选画面、下载图和CSV必须对应。化学结构/图版保持等比例缩放，局部放大不能拉伸。先检查正常网页宽度及窄屏，再检查导出。外链指向具体来源。正式正文不出现内部修订经过。

## 图版

采用用户认可的具体蛋白机制网络及配套数值面板，不退回抽象流程框和大量连线。蛋白名称、关系、实验注释及结论来自数据；关系区分激活/调控、抑制、结合/组装、间接联系。测量层级和物种必须清楚；转录下降不能染成蛋白功能抑制。

节点类型、线型和图例含义固定，颜色含义不能因新课题悄悄改变。无数据的关系不画成已知作用；某图形不适用于新课题则不用该面板，记录所缺能力，不虚构口袋或实验结果。

结构—口袋—接触—计算图复用已核对SMILES、共同骨架对应、实际姿势与接触记录。统一朝向和比例；几何接触保留距离阈值、分母与结构来源，不称为实测结合。

180 mm主图宽度，白底，统一字体/线宽/面板编号，输出SVG、PDF、PNG和对应数据表。图内仅数据、结构、短标签、单位和必要条件；完整图注在图外富文本。计算状态范围不等于实验误差；缺失效应量、误差、样本数保持缺失。

## 版本与生成

固定分析、显示投影和渲染程序各自版本。相同已审输入确定性导出；修科学内容时先改来源和正式分析，重新复核再生成。新增内部字段默认不进入输出，绝不在渲染时让AI重新推断。

独立DOCX不在默认生成或验收范围，历史文件保留。认可版原件保留；新版本另存。新课题可以沿用相同版式，但不能复制例题中的候选名单、机制、数值或结论。模板使用说明在技能里，不进入科研报告。
