# 质量检查与已发生错误

检查按四层分工：原始数据及执行记录；模型内容判断；明确矛盾程序检查；实际交付阅读。主执行者修源头，独立复核者核对原材料—科学判断—完整交付。没有独立复核者时不得把主执行者或程序更名为独立审核。

| 错误类别 | 必须检查的对象 | 程序能检查什么；内容复核仍需做什么 |
|---|---|---|
| 全范围未做就交付 | 每个候选、节点与参考记录 | 覆盖遗漏/待做状态；实际方法是否尽到、替代分析是否成立 |
| 身份与序列状态矛盾 | 可用、实际用、历史用、否决对应 | 使用记录与状态、版本匹配；物种与结构域适用性 |
| 蛋白功能错绑 | 原UniProt及原文归属 | 来源成员对应；不能把相邻记录机制移植到另一蛋白 |
| 多药论文串证 | 每条物质×条件×终点 | claim owner及引用；原文具体结论归谁 |
| 来源别名/汇总重复 | 原研究、条件、终点、摘要与全文 | 重复键提醒；独立条件不能机械合并 |
| 阴性含义错误 | 检测模式、刺激、剂量、时间、存活配对 | 结构化字段；Inactive是否检验了所谈抑制假说 |
| 计算与文字矛盾 | 同靶点范围、状态数、种子稳定性、比较协议 | 已审断言与数值；不能先称一致再忽略不稳定，不能跨蛋白加总 |
| 04表字段错位 | 对象、条件、终点、结果、解释 | 显式映射回读；语义是否正确不能靠表头过关 |
| 观察复制成解释 | 全部观察记录 | 完全重复拒绝；近义重复及真正新增解释由复核者判断 |
| 可推翻条件不对应 | 每个具体预测和条件 | 绑定字段及缺失；实际结果应更新哪一项判断 |
| 名单忽略敏感性 | 01、05、正文及原始证据 | 名单一致性；关键资料只有摘要时名额是否仍优于替代 |
| 新增内部字段污染报告 | 公共投影和三种导出 | 白名单、注入日志/SHA后的科学内容不变 |
| 检查发现错误仍成功 | 最后交付入口 | 注入实际错位/漏项/损坏文件后非零退出且不产生可发布结果 |
| 报告不可读/比例错误 | 00—07、四入口、筛选图、SVG/PDF/PNG、Word复制 | 边界、等比例、链接和载荷；正常尺寸的实际目视 |

不能只修一个已被标记的单元格。相同映射或科学组合逻辑影响的记录全部扩查，先更正输入或模型裁决，再重新生成。

保存首次产出、内部问题清单（位置、根因、依据、影响范围、处理）、重执行结果和最后验收。审核记录写明实际身份、读取材料位置、层级和范围。哈希仅核对文件版本，不能证明科学正确；完整哈希和日志只放核查附件。

新增脚本要用真实失败路径或代表性的反例执行验证，不只扫描是否存在某句代码。完成检查不可由导出器自行产生科学批准。工程测试、人工/AI内容复核和用户格式认可分别记录，不互相替代。

新课题第一次迁移从空白判断开始，用真实来源形成首次结果，再检查是否覆盖范围、是否保留关键反证、是否足以选物。测试用例的空白/合成数据只能证明程序拦截，不能声称新课题科研质量已验证。
