# 表达审校

以下四条为用户确认的原文，应在交付前实际执行：

1. 使用自然、完整的中文，语气符合具体场合。不要刻意添加俚语、亲昵语气或文艺表达。复杂问题充分解释，不为简短而省略必要信息。
2. 直接讨论已有的问题。纠正观点时，要有用户、材料或实际情境中的具体对象。没有需要纠正的观点时，直接陈述结论和理由。
3. 每段应提供信息、解释、依据或必要的操作提示。删除重复、空泛评价、口号和只用于营造气氛的句子。允许整句删除，无须换成另一句装饰性表达。
4. 保留影响结论、操作和理解的条件与限制。同一限制在合适位置说明一次，不反复声明。润色不得改变事实、数字、归因和不确定程度。

逐段判断读者是否能独立理解对象、作用、条件和结论。删去无信息口号、重复解释、无对象的反驳、编辑过程残留；已经通顺的段落不改。不为缩短文字删除科学边界，不用新套话填补删掉的句子。

| 已发生的问题 | 处理方式 |
|---|---|
| “不同入口能否解释共同反应？” | 写出所指对象，例如“不同候选可能作用于哪些通路蛋白？这些作用如何解释信号和毒性效应的差异？”；具体终点来自本课题 |
| “再判断是否适用专门案例” | 根据实际预测写清测量出现什么结果、更新哪项判断；没有推导依据则回到内容复核 |
| “修复种子不能当生物验证”“主线程逐条审读” | 从科研正文移到内部审查记录，保留已有的实验检验条件 |
| 观察和机制解释完全相同 | 保留观察；只有确有新增、可支持的解释时写解释 |
| 每个段落都重复“不是毒性概率”“仍需实验验证” | 在共同条件处说明一次；逐候选只保留会改变理解的特有边界 |
| 跨物种资料写成目标鱼直接证据 | 修正归因和类推前提，此项属于科学整改，不能仅润色 |

不使用无对象的“不是X，而是Y”纠正句；已有具体误解需要纠正时可直接解释对象与依据。图内缩写在首次出现或图例说明，正常正文尽量用中文名称，保留必要术语、引用和数据。

审校必须写回正式分析及其显示投影，再生成三种成果。不得只手工修改Excel或网页。自动程序可发现重复、字段错位、内部标记等明确问题；自然程度、推导是否对应和删改是否损害含义须由模型或实际复核者阅读判断。
