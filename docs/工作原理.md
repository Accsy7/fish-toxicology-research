# 工作原理

[English](METHODS.en.md) · [项目首页](../README.zh-CN.md) · [装载教程](装载教程.md)

鱼类毒性研究插件通过 LLM 分析论文、实验记录和计算结果，比较不同有机污染物对鱼类的潜在影响。分析会解释每种物质可能产生什么作用、为什么这样判断，并帮助研究者确定优先测试的物质和具体实验问题。

## 为什么采用 AI

比较一组物质时，研究者往往要反复查找文献、整理实验条件，再把分子、细胞和鱼类层面的结果联系起来。随着物质种类和文献数量增加，资料整理与逐项比较会占用大量时间。采用 LLM，主要看重以下三方面：

- **综合复杂关系。** LLM 能结合不同领域的知识，将结构变化、蛋白作用、暴露条件与整体效应放在同一问题中逐步分析，比较多种解释。例如，Co-Scientist 将 LLM 用于生物医学假说的提出与比较，并在所研究的案例中开展了实验检验。[Co-Scientist, 2026](https://www.nature.com/articles/s41586-026-10644-y)
- **减少大量资料的整理时间。** LLM 可以连续处理文献筛选、条件提取和表格整理，减少逐篇查找与反复录入的工作。在 LEADS 的医学文献研究中，专家借助专门训练的 LLM 完成筛选和数据提取时，用时均有缩短。[Wang 等, 2025](https://www.nature.com/articles/s41467-025-62058-5)
- **衔接检索与计算。** LLM 可以按任务选择工具，读取返回结果后安排下一步，减少在文献、数据库和计算程序之间来回操作。ChemCrow 已将这种方式用于化学查询、计算和合成规划。[ChemCrow, 2024](https://www.nature.com/articles/s42256-024-00832-8)

在本插件中，这些能力用于逐物质分析、风险分组和实验选物，让课题组能集中讨论作用差异与验证方案。

## LLM 怎样处理这些材料

**训练提供处理语言与概念的基础。** 以自回归 LLM 为例，训练会反复利用已有文本预测后续片段，并调整模型参数。大规模训练使模型学到词语、概念和表达方式之间的统计关系；任务说明与示例还能在当前上下文中引导它处理新问题。这为阅读、归纳和比较材料提供了基础。[Brown 等, 2020](https://arxiv.org/abs/2005.14165)

**Transformer 根据上下文组合信息。** 输入文字先拆成称为 token 的片段，再转成数值向量，并加入位置信息。自注意力为不同位置的信息计算权重，前馈网络进一步变换这些表示；多层处理使同一词语的表示能够随上下文变化。例如，分析“受体活性下降”时，周围的实验对象、处理条件和检测方法也进入计算。[Vaswani 等, 2017](https://proceedings.neurips.cc/paper/7181-attention-is-all-you-need.pdf)

**回答按上下文逐步生成。** 使用时，模型沿用训练得到的参数，根据当前上下文计算下一个 token 的概率分布。每生成一个新片段，上下文就随之扩展，再用于下一步生成。插件将课题要求、检索到的原文和工具返回结果放入上下文，供模型处理当前问题。

## 插件怎样把模型能力用于课题

**数据库提供研究资料。** SQLite 数据库及其前端保存化合物身份与结构、实验条件与效应、蛋白质及来源。LLM 按物质查询相关记录、读取原文，并补查本课题需要的公开资料，再把这些材料加入分析上下文。利用外部检索材料辅助生成回答，是检索增强生成（RAG）的基本思路。[Lewis 等, 2020](https://arxiv.org/abs/2005.11401)

**研究 skill 指导风险比较。** LLM 逐一分析各物质相对参照物的预期作用，说明哪些研究结果支持这一解释、哪些结果与之不符，以及预测适用的实验条件，再对整组物质排序或分组。研究结论相互冲突时，分析会追查物种、暴露条件或测量层级的差异，解释这些差异怎样影响判断，并列出有待进一步研究的问题。

**工具执行查询、计算和导出。** LLM 发起查询或计算，程序执行并返回结果，LLM 据此继续分析。插件已有资料提取、计算记录核查、绘图和导出工具；分子对接等专项计算按课题需要配置。图版、XLSX 和网页由同一份复核后的分析生成，呈现各物质的比较结果和推导过程。

## 这些分析怎样帮助实验

研究者首先得到整组物质的比较：哪些预计作用更强、哪些暂时可以并列，以及这些判断如何从文献和计算结果中得出。随后根据实验名额，选择能够回答不同问题的代表物。例如，一个用于检验较强效应，一个用于区分两种机制解释，另一个用于确认结构变化是否改变作用。参照物为这些比较提供共同基准。

选定代表物时，同时写明“什么结果会更新哪项判断”。下面以“某受体响应可能参与鱼类效应”为教学示例：

![假设某物质通过受体响应影响鱼类，分别根据响应与效应同时出现、只有响应、有效阻断后效应基本不变三种结果更新判断。](assets/methods-experiments.png)

**图 3｜受体作用的实验检验示例。** 虚线表示待检验的联系。表中结果的解释以各组暴露可比、存活情况已核查，以及观察时窗和检测灵敏度足以检出预期效应或差异为前提。

| 可能观察到的结果 | 对判断的影响 |
| --- | --- |
| 受体响应与鱼类效应均出现 | 增加对两者有关联的支持，继续检验受体是否参与产生该效应。 |
| 受体响应出现，鱼类效应未出现 | 下调该条件下的鱼类效应预测，重新检查从受体到整体效应的推导。 |
| 有效、特异地阻断受体后，鱼类效应基本不变 | 降低对“该效应依赖此受体”的支持，考察其他作用途径。 |

实验结果用于更新对应物质的判断，并重新考察机制和条件相近的未测成员。课题文件保存已有资料、判断理由和待验证问题，供课题组讨论选物、安排实验和继续研究。
