# 工作原理

[English](METHODS.en.md) · [项目首页](../README.zh-CN.md) · [装载教程](装载教程.md)

鱼类毒性研究插件帮助研究者比较一组有机污染物的潜在影响，并确定值得优先开展的实验。它将已有论文、实验记录和计算结果组织起来，为每个候选物给出预测、依据，以及能够改变判断的检验问题。

## 为什么采用 AI

实验前的困难往往是：候选物很多，证据却分散在不同研究中。有些物质有鱼类表型记录，有些只有细胞实验或蛋白层面的结果；物种、暴露浓度、时长和检测终点也不一致。要选择实验对象，需要先弄清这些结果能说明什么、彼此是否可比，以及哪些问题仍然没有答案。

大语言模型能够处理自然语言材料，联系分散的概念，并根据问题选择查询或计算步骤。这使它适合协助完成资料提取、条件比较、机制解释和假说整理。对于缺少同一实验条件下成套毒性数据的候选家族，可以先利用已有证据提出有条件的预测；若已有适用且经过验证的定量模型，也可以将其结果纳入比较。

已有研究提供了这种用法的实例：ChemCrow 将语言模型与化学工具结合，完成了文献查询、计算及合成相关任务；Co-Scientist 根据研究目标和既有资料提出假说，并在其研究的生物医学案例中开展了实验检验。[ChemCrow, 2024](https://www.nature.com/articles/s42256-024-00832-8) · [Co-Scientist, 2026](https://www.nature.com/articles/s41586-026-10644-y)

## 大语言模型怎样处理这些材料

**训练提供处理语言与概念的基础。** 以自回归语言模型为例，训练会反复利用已有文本预测后续片段，并调整模型参数。大规模训练使模型学到词语、概念和表达方式之间的统计关系；任务说明与示例还能在当前上下文中引导它处理新问题。这为阅读、归纳和比较材料提供了基础。[Brown 等, 2020](https://arxiv.org/abs/2005.14165)

**Transformer 根据上下文组合信息。** 输入文字先拆成称为 token 的片段，再转成数值向量，并加入位置信息。自注意力为不同位置的信息计算权重，前馈网络进一步变换这些表示；多层处理使同一词语的表示能够随上下文变化。例如，分析“受体活性下降”时，周围的实验对象、处理条件和检测方法也进入计算。[Vaswani 等, 2017](https://proceedings.neurips.cc/paper/7181-attention-is-all-you-need.pdf)

**回答按上下文逐步生成。** 使用时，模型沿用训练得到的参数，根据当前上下文计算下一个 token 的概率分布。每生成一个新片段，上下文就随之扩展，再用于下一步生成。插件将课题要求、检索到的原文和工具返回结果放入上下文，供模型处理当前问题。

**图 2｜自回归 Transformer 示意。** a 为训练，b 为使用过程，c 为注意力的信息加权。图中的权重与概率柱形用于展示计算过程。

## 插件怎样把模型能力用于课题

**数据库提供可以回查的材料。** SQLite 数据库及其前端保存化合物身份与结构、实验条件与效应、蛋白质及来源。AI 查询候选物的相关记录、读取原文，并补查本课题需要的公开资料，再把这些材料加入分析上下文。利用外部检索材料辅助生成回答，是检索增强生成（RAG）的基本思路。[Lewis 等, 2020](https://arxiv.org/abs/2005.11401)

**研究 skill 引导候选物比较。** AI 逐一分析候选物相对参照物的预期作用，整理主要依据、适用条件和反证，再形成全候选排序或分组。资料相互冲突时，分析会追查物种、暴露条件或测量层级的差异，并解释这些差异怎样影响判断。研究者据此查看选物理由和需要补证的环节。

**工具执行查询、计算和导出。** AI 发起查询或计算，程序执行并返回结果，AI 据此继续分析。插件已有资料提取、计算记录核查、绘图和导出工具；分子对接等专项计算按课题需要配置。图版、XLSX 和网页由同一份复核后的分析生成，便于查看预测与依据。

## 这些分析怎样帮助实验

研究者首先得到的是全候选比较：哪些物质预计作用更强、哪些可以并列，以及差异主要来自哪条证据。随后根据实验名额，选择能够回答不同问题的代表物。例如，一个用于检验较强效应，一个用于区分两种机制解释，另一个用于确认结构变化是否改变作用。参照物为这些比较提供共同基准。

选定代表物时，同时写明“什么结果会更新哪项判断”。下面以“某受体响应可能参与鱼类效应”为教学示例：

![假设候选物通过受体响应影响鱼类，分别根据响应与效应同时出现、只有响应、有效阻断后效应基本不变三种结果更新判断。](assets/methods-experiments.png)

**图 3｜受体作用的实验检验示例。** 虚线表示待检验的联系。表中结果的解释以各组暴露可比、存活情况已核查，以及观察时窗和检测灵敏度足以检出预期效应或差异为前提。

| 可能观察到的结果 | 对判断的影响 |
| --- | --- |
| 受体响应与鱼类效应均出现 | 增加对两者有关联的支持，继续检验受体是否参与产生该效应。 |
| 受体响应出现，鱼类效应未出现 | 下调该条件下的鱼类效应预测，重新检查从受体到整体效应的推导。 |
| 有效、特异地阻断受体后，鱼类效应基本不变 | 降低对“该效应依赖此受体”的支持，考察其他作用途径。 |

实验结果用于更新对应物质的判断，并重新考察机制和条件相近的未测成员。课题文件保存已有资料、判断理由和待验证问题，供课题组讨论选物、安排实验和继续研究。
