# 装载教程

[English](https://github.com/Accsy7/fish-toxicology-research/blob/main/docs/INSTALL.en.md) · **简体中文** · [项目首页](https://github.com/Accsy7/fish-toxicology-research/blob/main/README.zh-CN.md)

## 1. 选择你使用的软件

支持WorkBuddy、DeepSeek Harness、Claude Code、Claude Cowork／Desktop、Codex、ChatGPT。下面只需展开对应的一项。

## 2. 下载与准备

1. **下载完整包。** 下载 [fish-toxicology-research-workpack.zip](https://github.com/Accsy7/fish-toxicology-research/releases/latest/download/fish-toxicology-research-workpack.zip)，其中已包含插件、SQLite数据库和数据库前端。

2. **本地使用。** 将ZIP完整解压，保留内部目录结构。解压出的工具文件夹保存插件和数据库；另建或使用已有的课题文件夹，存放自己的文献、数据与研究成果。在AI软件中打开课题文件夹，再按下一节装载插件。同一个工具文件夹可以供多个课题使用。

3. **云端使用。** 使用ChatGPT网页或云端Work时，上传完整包ZIP及研究资料，再按下方对应小节装载。

GitHub的 **Code → Download ZIP** 和Release中的 **Source code** 下载的是源码仓库。数据库及前端随 `fish-toxicology-research-workpack.zip` 分发，需要使用资料库时，请选择上面的完整包下载。

## 3. 装载插件

<details>
<summary>WorkBuddy</summary>

1. 从[官网](https://www.workbuddy.cn/work/)安装WorkBuddy，在任务中选自己的课题文件夹，使用Agent模式。

2. 在“技能 → 添加技能 → 上传技能”导入`adapters/workbuddy/fish-toxicology-research.zip`并启用。

3. 把工具包内的`toolkit/INSTALL.md`交给AI，说：“把这个研究工具接入当前项目。”

[官方装载说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)

</details>

<details>
<summary>DeepSeek Harness</summary>

1. 从[DeepSeek官网](https://www.deepseek.com/zh/harness/)下载Harness，打开自己的课题文件夹。

2. 把`toolkit/INSTALL.md`交给AI，说：“把这个研究工具接入当前项目。”

3. AI完成接入后，直接提出研究问题。

[官方skill说明](https://deepseek-harness.github.io/deepseek-harness/en/reference/subsystems/skills)

</details>

<details>
<summary>Claude Code（含Desktop中的Code模式）</summary>

1. 按[官方说明](https://code.claude.com/docs/en/overview)安装或打开Claude Code，进入自己的课题文件夹。

2. 把`toolkit/INSTALL.md`交给AI，说：“把这个研究工具接入当前项目。”

3. 直接提出研究问题；也可输入`/fish-toxicology-research`调用技能。

[官方skill说明](https://code.claude.com/docs/en/skills)

</details>

<details>
<summary>Claude Cowork／Desktop</summary>

1. 在[Claude Desktop](https://claude.com/download)中使用Cowork或可执行任务的模式，并允许访问课题文件夹和工具包。

2. 在“Customize → Skills → ＋ → Create skill → Upload a skill”上传`adapters/claude/fish-toxicology-research.zip`并启用，开启代码执行与文件创建。

3. 把`toolkit/INSTALL.md`交给AI，说：“把这个研究工具接入当前项目。”Desktop中的Code模式按上一项操作。

[官方上传说明](https://support.claude.com/en/articles/12512180-use-skills-in-claude) · [Cowork文件访问](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork)

</details>

<details>
<summary>Codex／ChatGPT桌面端的本地工作</summary>

1. 在支持本地执行的Codex中打开自己的课题文件夹。

2. 把`toolkit/INSTALL.md`交给AI，说：“把这个研究工具接入当前项目。”

3. 直接提出研究问题；也可用`$fish-toxicology-research`调用技能。

[官方skill说明](https://learn.chatgpt.com/docs/customization/overview#skills)

</details>

<details>
<summary>ChatGPT网页／云端Work</summary>

1. 新建对话，上传完整工作包ZIP及本次研究资料，使用能解压、运行代码并生成文件的环境。

2. 说：“读取工具包中的toolkit/INSTALL.md，把这个研究工具接入当前项目。”

3. AI确认能读取资料并运行工具后，直接提出研究问题。

工具在当前对话环境中运行。新建对话时，重新上传工具包和所需资料，再执行装载步骤。[云端文件说明](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-overview#cloud-work)

</details>

## 4. 确认装好并开始研究

由AI检查三件事：读到研究skill、能访问本次资料、能运行查询与导出工具。随后用一句话说明研究问题，例如：

> 研究双酚类对斑马鱼的雌激素相关毒性，以BPA为参照，比较风险并选出实验代表物。

成果包括图版与数据、Excel和网页。本地成果保存在课题目录的`research/`中，下次打开同一项目即可继续；云端成果请下载保存。

## 5. 遇到问题时怎么办

| 情况 | 告诉AI |
| --- | --- |
| 找不到skill | “请检查当前软件的技能装载位置，并读入研究流程。” |
| 无法访问本地文件 | “请说明需要开放哪个文件夹，或提供哪些文件。” |
| 数据库未连接 | “请检查资料库路径；没有资料库时先使用我提供的材料和公开资料。” |
| 缺少运行依赖 | “请在本项目中补齐依赖，再验证查询和导出。” |
